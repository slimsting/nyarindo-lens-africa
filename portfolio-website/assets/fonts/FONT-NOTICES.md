# Font Notices

These local WOFF2 files are subsets of fonts distributed through Google Fonts:

- DM Sans
- DM Mono
- Manrope
- IBM Plex Sans
- IBM Plex Mono

The font families are licensed under the SIL Open Font License 1.1. The files are self-hosted
so public pages do not make cross-origin requests to Google Fonts.

Source version URLs were retrieved from the Google Fonts CSS API on 2026-11-02. Individual
font source projects:

- https://github.com/googlefonts/dm-fonts
- https://github.com/sharanda/manrope
- https://github.com/IBM/plex
